# US20 服务端与用户端源码

本目录仅归档本次 US20 实验实际使用的程序源码、测试源码和实验驱动入口。没有加入实验结果包、图片、原始观测、GNSS 产品、运行日志、目标文件或可执行文件。

## 目录

- `server/src/`：20 参考站 GPS/Galileo/BDS 联合服务端源码及原有构建文件。
- `user/src/`：MTA1、PKRD、P800 用户实验对应的完整源码文件快照，已按实际构建的覆盖层顺序展开。
- `contracts/`：对流层、重置、检查点和用户状态转换等相关测试源码。
- `drivers/`：13:10—14:10 GPST 一小时回放、单 Galileo 和关闭区域大气约束的驱动源码。
- `SOURCE_MANIFEST.json`：所有归档源码的 SHA256，以及两端实际构建清单的身份信息。

两端的源树分别保存，不能直接相互覆盖。它们对应不同的已运行构建；这里没有把两个版本合并成一个新的、未经验证的程序版本。本分支原有的顶层 `src/` 保持不变，本次归档的两个版本以本目录中的源树为准。

## 区域大气约束开关

最新单 Galileo 重跑仅改变以下用户端环境开关：

```sh
export ZHANG_USER_REGIONAL_IONO=OFF
export ZHANG_USER_REGIONAL_TROP=OFF
```

这两个开关关闭区域电离层和区域 ZTD 伪观测，保留用户端 STEC/ZTD 状态估计及原有物理模型。区域联合钟差／相位产品协方差处理仍保持原设置；不应通过关闭整个区域协方差模块来替代上述两个开关。

`drivers/` 保留当时工作流的源码入口与路径关系，需要相应输入和配套工具。此次同步不迁移数据、不重新解算、不更新服务端或用户端正在使用的二进制，也不表示新完成了一次程序重编译。
