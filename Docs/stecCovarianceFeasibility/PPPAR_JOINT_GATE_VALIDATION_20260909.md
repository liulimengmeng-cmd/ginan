# PPP-AR 联合一致性拒绝检查：实现与验证

## 范围

结论：拒绝路径与浮点回退已验证有效，但当前名义门限几乎拒绝原始 CODE 对照的全部候选，因此还不能将它作为正式固定方案默认启用。应继续研究候选的联合选择与误差模型一致性，不能通过抬高门限恢复表面固定率。

本次实现第一阶段保护：完整网络候选在任何 AR 更新、后验降权之前进行联合检查；不通过则整组不提交，保留当历元浮点状态。不改变整数搜索，不自动采用前次诊断中的替代整数，不改 CODE 码 OSB、相位 OSB 或其不确定度。

当前是显式启用的实验实现：运行环境设置 `GINAN_AR_JOINT_NIS_GATE=1`。未设置时保留原路径。尚未将此拒绝规则作为经过科学标定的默认产品配置。

源码：`src/cpp/pea/pppArJointGate.hpp` 定义纯计算检查；`src/cpp/pea/ppp_ambres.cpp` 在更新前调用，并将拒绝状态传播至双频候选的输出元数据。此次所有运行使用双频候选路径。

## 门限来源与边界

计算 S = H P Hᵀ + R，NIS = vᵀ S⁻¹ v，保留完整跨站协方差。使用 Cholesky 分解；非有限值、不对称、非正定协方差及无效参数均拒绝，不做协方差修补或行降权。

沿用现有 `KFState.chiSquareTest.sigma_threshold` 的双尾正态换算约定：alpha = erfc(sigma / sqrt(2))，门限为自由度等于候选行数的卡方上尾分位点。两次运行实际 sigma 均为 4，alpha = 6.334248366623993e-5。AR 拒绝检查由上述独立实验开关启用，不依赖原滤波器卡方开关是否启用；它只复用已有 sigma 参数及其约定。

该门限不是针对异常事件调整的常数，也不是整数错误率保证。整数经过候选搜索，且观测/先验误差可能偏离名义高斯模型；通过只能标为 `PASSED_NOMINAL_SCREEN`，继续提交后仍为 `SUBMITTED_UNVERIFIED`。没有整数真值，因此不能测出误拒率。

拒绝 TRACE 使用 `KEEP_FLOAT_NOT_SUBMITTED`；双频诊断状态为 `JOINT_CONSISTENCY_GATE_REJECTED`，`ar_pseudoobservations_submitted=0`。现有 COV 文件粗粒度 `posterior_stage` 仍沿用原有“NO_RESOLVED_COMBINATIONS”字符串；区分本次联合拒绝应读取新增的具体诊断状态和提交标志，而不是把该旧字符串或候选行数当成固定率。

原始产品没有人工 10 mm 实验中的同等跨站暴增，不代表它满足名义高斯联合检验。当前结果说明候选与名义协方差广泛不一致，但不能区分候选错误、协方差物理标定不足、观测模型残差和搜索后检验分布偏离，也不能把 2432 次拒绝称为 2432 次错误固定。

因此本轮只交付并验证实验保护机制，不宣称修复了可靠 PPP-AR。保持原始 CODE 产品作为主对照，下一步应在冻结快照上用小规模完整网络整数搜索或保留多候选的联合组合方法，确定联合最优/有界候选的代价，并分别检查原始产品下的单站绝对残差与不确定度。先前 10 mm 的替代整数虽将 NIS 降到 106.78，仍高于本次 20 行门限 53.73，也不能因目标函数改善就直接接受。
