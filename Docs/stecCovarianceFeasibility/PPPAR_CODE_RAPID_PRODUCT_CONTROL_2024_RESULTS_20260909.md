# 2024 CODE rapid 产品替换 PPP-AR 实验结果

## 结论

切换到同源 CODE rapid SP3/CLK/ERP/OSB 后，GINAN 的整数反馈路径大量运行：
全天 2809/2880 个网络历元出现至少一个站的整数伪观测提交，六站合计
16749/17280 个站历元出现反馈。然而，这不是可信的 PPP-AR 固定率。

原因很直接：CODE 当日 L1C/L2W phase OSB 的 Bias-SINEX 形式标准差全部为
0，持久 phase-OSB 状态模型因而退化成把产品当作确定改正。高反馈率随之
恢复，但整数约束的归一化信息量和非线性实现一致性仍不合格：NIS/row
中位数为 8.239，shadow 与实际滤波状态的最大差为 1.399 m。14:00–24:00
窗口内，AR 三维 RMS 为 0.0248415 m，配对 FLOAT 为 0.0247168 m，AR 反而
恶化 0.0001247 m。当前结果证明 CODE 的整数钟/OSB 链能驱动候选与反馈，
但没有证明固定正确或带来坐标收益。

## 实验设计

四个 24 h 解算使用相同 2024-07-17 观测、六站、GPS L1C/L2W、G01 排除、
15° 高度角、接收机单差整数坐标、成功率门限 0.9999 和 ratio 门限 3：

| 配置 | phase-OSB 语义 | code-OSB 语义 | 整数行为 |
|---|---|---|---|
| 4a | 条件化确定改正 | 条件化确定改正 | 反馈 |
| 4b | 同 4a | 同 4a | FLOAT probe-only |
| 4c | 单个 86400 s 持久状态先验 | 原逐历元形式方差 | 反馈 |
| 4d | 同 4c | 同 4c | FLOAT probe-only |

4c/4d 关闭 receiver chunking，以保留共享卫星 phase-bias 状态的跨站协方差。
4a/4b 使用原按接收机分块设置。由于 CODE phase-OSB 方差为零，4a 与 4c
在数值上近乎等价；这正是本实验识别出的产品不确定度边界。

## 固定活动与统计一致性

| 模型 | 反馈网络历元率 | 六站历元反馈率 | 提交秩覆盖 | NIS/row 中位数 | shadow 最大状态差 | 科学接受 |
|---|---:|---:|---:|---:|---:|---|
| 4a CODE 条件化 | 2809/2880 = 97.5347% | 16749/17280 = 96.9271% | 81.9438% | 8.23940 | 1.39872 m | 否 |
| 4c CODE 持久状态 | 2809/2880 = 97.5347% | 16749/17280 = 96.9271% | 81.9447% | 8.23932 | 1.39872 m | 否 |
| WUM M2 持久状态 | 0/2880 = 0% | 0/17280 = 0% | 0% | 无反馈 | 无反馈 | 否 |

“反馈率”只表示跟踪到
`FILTER_CALL_RETURNED_SUBMITTED_UNVERIFIED`，不是经过整数真值验证的固定率。
首次反馈时间为 35.5–52.5 min。16749 个站历元通过已实现的双频门控；其余
包括 33 个不完整双频图、87 个第二阶段成功率不足、5 个第二阶段 ratio 不足，
以及宽巷阶段的候选维数、成功率或 ratio 失败。所有候选行本身均通过数值
结构检查，但有 33 个网络历元存在一个未配对 ambiguity，因此全日结构审计
不能标记为完全闭合。

## 收敛后坐标精度

这里“收敛后”是预先固定的 14:00–24:00 UTC 分析窗，不是从结果自动挑选
的最优起点。参考为 IGS 周解坐标 SINEX，未推断站速传播。每个解共 7200 个
站历元，4a/4b 和 4c/4d 均达到 100% 精确时间匹配覆盖。

| 解 | 3D RMS | 水平 RMS | 垂直 RMS | 相对配对 FLOAT 的 3D RMS |
|---|---:|---:|---:|---:|
| 4a CODE AR | 0.0248415 m | 0.0052098 m | 0.0242890 m | 0.0020583 m |
| 4b CODE FLOAT | 0.0247167 m | 0.0049409 m | 0.0242179 m | — |
| 4c CODE AR | 0.0248415 m | 0.0052098 m | 0.0242890 m | 0.0020583 m |
| 4d CODE FLOAT | 0.0247168 m | 0.0049410 m | 0.0242179 m | — |
| WUM M2 AR/FLOAT | 0.0252266 m | 未在旧审计中输出 | 未在旧审计中输出 | 0 m（无反馈） |

CODE FLOAT 相对 WUM M2 FLOAT 的 3D RMS 改善约 0.51 mm（2.02%），因此可
归因于产品链变化的可见收益很小，而且出现在 FLOAT 本身。CODE AR 相对自己的
FLOAT 在 3D、水平和垂直方向分别恶化约 0.125、0.269 和 0.071 mm，不能宣称
AR 提升。

## 外部偏差和产品审计

- 四个全天解各有 496919 条外部 bias 应用记录，唯一键也是 496919，缺失 0、
  重复 0。
- 4c/4d 各有 62 个卫星/信号 phase-bias 状态，均只初始化一次；其先验方差
  全为 0，因为产品没有提供非零 phase-OSB 形式方差。
- 产品链审计确认 G01–G32 的 day-199 SP3、30 s CLK 和 C1C/C2W/L1C/L2W
  BIA 全日覆盖完整。
- CODE 报告将该 CLK 与 accompanying code/phase biases 定义为可用于 PPP-AR
  的整数钟产品链。但 Bias-SINEX 规范说明，从外部来源取入的 bias 值可用 0
  标准差标记，因此 0 不能被解释成物理上无误差。

## 下一步判断

不应继续降低成功率或 ratio 门限。当前优先问题不是“固定不出来”，而是
“零方差产品被当成确定约束后，固定很多但统计不可信”。下一步需要给 CODE
phase OSB 引入可辩护的非零不确定度模型，并做尺度扫描：例如固定公共模结构，
只扫描 phase-OSB 残差 sigma，要求同时满足 NIS/row 接近 1、shadow 实现误差
显著下降、AR 对 FLOAT 的独立精度有稳定改善。没有这些条件，不应把 96.93%
写成有效 PPP-AR 固定率，也不应输出“fixed STEC”。
