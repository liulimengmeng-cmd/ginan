# 当前历元周跳 QC 实验（2026-10-18）

本目录是服务端 GPS 接收机—卫星链路的周跳 QC 修改及验收工具，不是用户端 PPP 固定策略修改。整网 AR／产品联合 NIS 保持 `SKIPPED_RATIO_ONLY`，网解 ratio 仍为 2；局部链路的协方差加权 QC 统计仍启用，不能将两者混为一谈。

## 修改内容

- 保留逐信号 LLI、半周及真实观测间隙的保守处理。单频 LLI 不应因为旧 GF／SCDIA 级联而自动退休另一健康频率。
- 独立使用外部精密轨钟计算 IF 几何检查，不使用已经吸收本链路观测的当前 KF 卫星钟。
- 在同一时间窗口使用固定的其他卫星组合消除接收机钟，传播同一线性组合的方差。禁止逐历元累加中位数后忽略累计误差的时间相关性。
- GF 外推失配不能单独触发隔离或断弧。相位 QC 首先检查 IF 与可用的三频消电离层组合。
- 使用实际保存的 `D1C/D2W` 构造几何无关相位速率。仅有字段但本历元为零／缺失时，不伪造可用的多普勒。
- 增加弱同周跳的预声明方向匹配检验，并分配局部多重检验的名义误报预算。该检验只提供早期隔离，不直接颁发整数证书。
- IF／三频组合的预测使用事前常数、线性、二次模型的加权组合，并传播模型间不确定度；候选观测不参与模型选择。
- 对弱同周跳，检验最近八个可能的事件位置，每个位置冻结此前最多 64 点参考，联合检查最多八个后续样本，并保留它们之间的完整预测协方差。后续样本不能反过来把自身的跳变拟合成趋势；该检验不使用 GF 触发断弧。
- 接受历史最多 32 点，原始筛查历史最多 96 点；一般阶跃扫描仍限制为最近 64 点，保持原多重检验预算。可疑样本不进入接受历史。检查点保存这些有界历史。

## 无多普勒的受限 GF 辅助检验

旧版只在多普勒可用时利用 GF／相位的联合方向；没有多普勒时，弱同周跳可能在首拍未触发后进入基线，随后被外推模型吸收。

新增路径只使用事前数据，比较 32／16 点或 16／8 点二次 GF 外推。模型必须通过事前拟合适用性与共享噪声下的预测一致性检查，不能由当前 GF 创新来选择模型。即使模型通过，仍要求 IF／三频相位对同一阶跃方向提供至少 2σ 支持，并通过联合拟合检验。GF 单独变化不能触发该路径。

首拍相位证据不足时，对最近八个候选事件冻结事前参考，将后续相位与 GF 一起投影。共享原始相位的交叉协方差及未来时间的完整协方差均保留；GF 模型误差采用与原单步方差率一致的 Brownian 协方差。这是待回放验证的误差模型，不是真实电离层变化的保证。

所有新增 GF 辅助只授权 `PHASE_SUSPECT`，不直接进入整数退休认证。不能把弱报警包装为已识别的物理周跳，也不能自动回滚此前已经使用的观测。

新增即时检验的名义族门槛按无多普勒 2 项、有多普勒 6 项分配；历史窗口的相位／GF 共 16 项共享 1e-5 名义预算。窗口数量及实际族大小均计入阈值，不能增加检验后仍使用旧的单项门槛。实际误报和延迟另由同噪声配对控制验收。

TRACE 的 `early_stage`：0 表示没有使用新增辅助，1 为当前历元受限 GF，2 为冻结事件参考的多拍 GF，3 为固定两拍多普勒。`trend_assisted` 不等于整数认证成功。

## 多普勒差分及协方差

令 `G = lambda1*L1 - lambda2*L2`，`gdot = -lambda1*D1 + lambda2*D2`。

每个区间构造：

`e[k] = G[k] - G[k-1] - dt/2 * (gdot[k] + gdot[k-1])`。

单频多普勒积分在实际 MAL2 数据中存在分米级误差，不能直接拿来识别一周；双频差分消除了共同的几何／钟项。其噪声仍需使用过去数据校准，不能把多普勒视为精确真值。

相邻 `e` 共享相位和多普勒：相位的共享系数异号，多普勒的共享系数同号。因此先建立三对角协方差，再用等价的线性时间 LDLT 创新递推白化，并同步传播与 IF／三频组合共享相位的交叉协方差。

单测另外从原始变量线性变换构造完整稠密协方差，比较条件创新、方差及交叉协方差。该参考计算不调用三对角递推。

原有多普勒共识路径要求 GF 外推与多普勒推导的增量一致，比较中当前 GF 相消。新增无多普勒路径使用上面的事前趋势检查，不伪造多普勒。新增固定两拍多普勒路径只测试一个预声明滞后位置，保留第一拍证据；其未知常偏差和预测协方差通过事前 GLS 同时传播。

## 隔离与断弧必须区分

`PHASE_SUSPECT` 表示当前观测不进入相位估计，不等于已经识别周跳整数，也不等于已经修复它。

整数退休仍经过完整的局部整数置信椭球枚举：零跳必须被排除、候选必须满足数值及拟合检查，预算耗尽返回未知。多个整数仍可能时标记 `CONTINUITY_UNKNOWN_PHASE_STEP`，不得将其包装为已识别的物理周跳。

多普勒辅助检验自身不直接退休相位弧。自然数据的 LLI=0 也不是完美的无周跳真值。

## 检查点与离线启动

原始 01:59:30 FLOAT 检查点不修改。旧 receiver schema 2 的缺失 QC 历史，在显式开启 `ZHANG_R51_SLIP_RAW_WARMUP=1` 时，从同源原始文件读取此前 32 分钟。只复制检测器历史，并检查前一历元原始 LC 与检查点端点一致；不改 KF、物理弧或产品状态。

外层 receiver schema 保持 3，内部 sample 使用 Boost class version 1 保存多普勒状态。测试包括：独立旧布局写入器到新读取器的迁移、旧读取器拒绝新布局、有界历史往返，以及真实旧 schema-2 快照的解码。解码测试不冒充已经完成全网 KF／图的重放。

`run_validation.py` 在不可覆盖的新证据目录中保留关键源码、PEA 二进制和哈希，完成 CTest、同噪声配对注入／无注入控制、快速电离层变化、平滑相位趋势、多普勒粗差、原始 MAL2 回放、整数网格和旧检查点测试，最后再次核对哈希。失败报告也必须保留，调参后的版本必须使用新的独立噪声样本验证。

除普通原始回放，还用 `prepare_without_doppler.py` 生成仅清空 GPS 多普勒字段的派生 RINEX。原始码、相位与 LLI 值不变，生产读取器及原始历史初始化均读取该副本；不能只在当前拍将 D 置零，却在初始化时继续使用原始文件的多普勒。原始输入及旧检查点的哈希在测试前后核对。

独立单测分别以 QR 外推和原始变量稠密变换重构 GF 时间／交叉协方差，以稠密 GLS 重构两拍多普勒的常偏差预测协方差，不再次调用同一核心求解器冒充参考实现。已知的 690／810 秒等长尾样例另设不可豁免的回归门禁。

`freeze_offline.py` 只接受通过全部功能及性能门禁的报告。`start_offline.py` 只派发独立输出目录的离线实验，不停止其他求解器。旧输出、旧检查点和原始观测均保留。

目标时段为 `2024-07-17 02:00:00–02:59:30 GPST`。新实验开启 receiver TRACE、level 2，用于记录真实 QC 判决；因此总耗时不能与原 V5 的 level 1 不加说明地直接比较。

## 解释结果的边界

- “当前历元检出”可以使用过去的有界观测历史，并不代表完全无历史或冷启动即有相同能力；AR 仍是当前历元独立搜索，不复用历史整数。
- 180 站中只有 121 个文件头声明所选双频多普勒，实际逐历元可用率还可能更低；有、无多普勒的时效必须分开报告。
- 同噪声无注入控制在事件历元已被隔离的样本，不记作由注入新触发的当前历元检出。
- 整数误判计数覆盖所有受测链路：无注入链路产生 `INTEGER_STEP` 也必须计为错误整数证书，而不是仅记录错误断弧。旧版验收报告的该字段只覆盖注入目标；旧版的零误断弧门禁仍然有效。
- 有限高斯仿真和单站真实回放不证明真实全网误报率为零，不证明实时绝不漏检，也不证明最终产品质量或用户端定位收益。
- 检出前若仍使用了受周跳影响的相位，后续隔离不会自动回滚这些滤波更新。最终报告必须保留尾部延迟，而不只给平均数或 P95。
